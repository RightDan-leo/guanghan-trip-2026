# 广汉旅行行程

2026 年 10 月 3 日至 5 日广汉美食、三星堆与麻将行程。

此站为无需构建的静态网页，入口为 `index.html`，无需安装依赖。

## GitHub Pages

发布源设为 `main` 分支根目录 `/`。

在仓库的 Settings → Pages 中选择 Deploy from a branch，然后选择 main 和 /(root)，保存。

参考：[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。
